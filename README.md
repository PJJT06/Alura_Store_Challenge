📊 Análisis Estratégico de Tiendas – Proyecto Data Science
📌 Descripción del Proyecto

Las ciencias de datos han tomado gran relevancia en las últimas décadas, especialmente con el crecimiento del comercio digital. La capacidad de interpretar datos permite transformar información en decisiones estratégicas.

El objetivo de este proyecto es asesorar a un comerciante en la toma de decisión sobre la venta de una de sus cuatro tiendas, utilizando un análisis basado en datos reales.

La decisión se fundamenta en métricas clave como:

  -Ingreso total por tienda

  -Calificación promedio del cliente

  -Costo promedio de envío

  🎯 Objetivo

Determinar cuál de las cuatro tiendas debería ser vendida, minimizando el impacto financiero y estratégico sobre el negocio global.

🛠️ Tecnologías Utilizadas

  -Python

  -Pandas

  -Google Colab

  -GitHub

📂 Fuentes de Datos

Se analizaron cuatro conjuntos de datos correspondientes a cada tienda:

  -tienda_1.csv

  -tienda_2.csv

  -tienda_3.csv

  -tienda_4.csv

Cada dataset contiene información sobre:

  -Producto

  -Categoría

  -Precio

  -Costo de envío

  -Fecha de compra

  -Vendedor

  -Lugar de compra

  -Calificación del cliente
